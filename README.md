# AI Document Assistant

A Python-based RAG application for PDF question answering, with LLM API reliability monitoring.

## Project Goals

- Upload and process PDF documents.
- Extract and chunk document text.
- Generate embeddings.
- Store and retrieve document embeddings.
- Integrate an LLM API for contextual answers.
- Monitor API latency, request counts and errors.
- Containerize the application using Docker.
- Manage services using Docker Compose.

## Technology Stack

- Python
- FastAPI
- RAG
- Embeddings
- Vector Database
- LLM API
- Docker
- Docker Compose
- Prometheus
- Grafana
